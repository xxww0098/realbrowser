# 环境管理

- **模式与范围：** Operate；本地桌面端的环境管理首页。
- **用户与任务：** 电商运营人员快速找到、创建、配置指纹、打开、停止、重命名和归档独立浏览器环境。
- **主要动作：** 新建环境；行内打开/停止与指纹设置是第二层动作。
- **证明内容：** 独立 Profile、原生 Persona、直连网络和检测到的 Chrome 版本均来自本地控制面；浏览器预览数据明确标为合成数据。
- **约束：** 主工作区只用连续单列；创建与重命名使用弹窗；不设常驻左右分栏；主界面文案只保留名称、状态和动作；圆角柔和，边线为暖灰低对比 1px，阴影只表达真实浮层。

## 选定方向

批准的视觉稿：`/Volumes/Acasis/Code/REPO/realbrowser/.impeccable/mocks/adspower-environments.png`。

采用 AdsPower 类商业操作台的紧凑图标轨、清晰页标题、横向搜索/筛选、蓝色首要动作和占满余下视口的环境表格。用户提供的边线参考进一步约束为暖灰细分隔线、较强但仍克制的控件描边，以及 11–14px 控件、19px 主表面的柔和圆角层级。整体密度以长时间操作为准，避免展示型大字号和大控件。

## 可见元素与实现介质

| 元素 | 承诺 | 介质 | 处理 |
| --- | --- | --- | --- |
| 导航轨 | 76px、图标优先、活动项皇家蓝 | React + Lucide + 品牌 SVG | 匹配；未开放项禁用并提供提示 |
| 标题与工具区 | 单个页面标题、宽搜索、状态筛选 | 语义 HTML + CSS | 匹配；删去说明书式副文案 |
| 新建环境 | 视觉最强的蓝色按钮 | shadcn 风格 Button | 匹配；不复制竞品图标和文案 |
| 批量动作 | 视觉稿包含选择后动作 | 不实现 | 可接受省略；MR-0 没有批量选择能力，避免伪造交互 |
| 环境表格 | 紧凑行高、轻分隔、行内状态与动作 | 语义 table + React | 匹配；数据较少时保留安静留白 |
| 商店图标 | 视觉稿用平台标识增强识别 | 不实现 | 可接受替换；PRODUCT.md 禁止把示例平台归属当作产品事实 |
| 创建/重命名 | 临时打断而非永久详情列 | Radix Dialog | 用户明确允许弹窗，并禁止常驻左右分栏 |
| 指纹设置 | 区域、设备、网络与浏览器表面的完整 Persona 表单 | 临时右侧 Sheet + Rust Persona schema | 用户要求本阶段配齐；抽屉关闭后主工作区仍为单列 |
| 类型 | 强标题、紧凑工作型正文 | 系统中文 UI 字体栈 | 可接受字体替代；桌面 Operate 模式优先原生清晰度 |
| 材质 | 白色平面、暖灰细线、真实浮层轻阴影 | CSS | 匹配；无照片、仿材质或装饰性渐变 |
