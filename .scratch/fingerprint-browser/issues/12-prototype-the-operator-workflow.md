# Prototype the Operator Workflow for 200 Stored and 20 Active Identities

Type: prototype
Status: open
Blocked by: 06, 08, 09, 11

## Question

What information architecture and interaction model lets one operator safely create from an Identity Template, find, group, tag, inspect, launch, stop, archive, and diagnose up to 200 stored Browser Identities with 20 active windows? Produce a rough interactive or visual prototype that makes identity labels, platform/account metadata, Persona summary, Network Egress health, extension state, recovery state, batch actions, window arrangement, and dangerous actions unambiguous. Include an opt-in synchronization concept so human feedback can decide whether input broadcasting is safe enough to ship and what confirmation boundaries it requires.
