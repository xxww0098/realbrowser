# Define the Browser Persona Contract

Type: grilling
Status: open
Blocked by: 01, 03, 04, 05

## Question

Which observable characteristics belong to a Browser Persona, which remain the stock browser or operating-system truth, what is stable per Browser Identity versus per origin, and what consistency constraints must hold across JavaScript, request headers, rendering, media devices, locale, timezone, screen geometry, and network-derived location? Decide how a Persona is generated, versioned, migrated, inspected, and disabled without promising undetectability.
