# Choose the Browser Integration Architecture

Type: grilling
Status: open
Blocked by: 01, 02, 03, 04

## Question

Which supported seams should own Browser Identity launch, browser lifecycle, Browser Persona configuration, Network Egress, health checks, and local control: command-line switches, a managed extension, native messaging, CDP, or a deliberately limited combination? Decide the trust boundaries and explicitly reject mechanisms whose compatibility, security, or maintenance cost is unacceptable.
